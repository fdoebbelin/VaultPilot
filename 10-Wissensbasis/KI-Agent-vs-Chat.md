# KI-Agent vs. KI-Chat

## Überblick

## Abgrenzung

### KI-Chat
- Reine Interaktion: Eingabe → Ausgabe
- Kein Zugriff auf externe Tools / Schreibrechte
- Ergebnis: Text, ggf. generierte Inhalte

### KI-Agent
- Ziel gerichtet, plant, nutzt Tools, iteriert
- Funktionsweise: **Ziel → Plan → Tool-Use → Iteration**
- Kann Aktionen im System ausführen (z. B. Dateien schreiben, Befehle ausführen)

## Vergleich

- **Stärken KI-Chat:** Schnelle Verfügbarkeit, einfache Nutzung, Ideenfindung
- **Stärken KI-Agent:** Durchführung komplexer Aufgaben, Iteration bei Blockaden
- **Kritische Würdigung:** Agenten sind fehleranfälliger (Planung, Tool-Use), Chats flexibler

## Relevanz für VaultPilot

Der Agent (VaultPilot) nutzt das OpenCode-Äquivalent: Ziel → Plan → Tool-Use → Iteration, um Wissensnotizen zu erstellen, zu strukturieren und zu vernetzen.
