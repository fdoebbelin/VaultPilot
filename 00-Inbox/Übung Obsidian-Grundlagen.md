# Übung Obsidian-Grundlagen

Praktischer Durchlauf der Übungen aus [[10-Wissensbasis/Obsidian-Grundlagen]] (C.0, Umsetzung-Checkliste). Dauer: ca. 5 Minuten. Diese Notiz ist die Abarbeitungsliste – Kästchen nach Abschluss ankreuzen.

## Tastenkürzel

- [x] `Strg+O` – Quick Switcher: „git" tippen → Notiz `Git-Grundlagen` öffnen
- [x] `Strg+P` – Befehlspalette: „graph" tippen → Graph-Befehle erscheinen sehen
- [x] `Strg+Shift+F` – Globale Suche: „Wikilink" suchen → Treffer über alle Notizen
- [x] `Strg+E` – Ansicht umschalten (Lesen ↔ Bearbeiten) bei einer Notiz testen
- [x] (Optional) `Strg+N` – Neue Notiz, dann `[[` tippen → Autocomplete sehen

> **Vorsicht bei der Wikilink-Übung:** Einen **echten** Notiznamen verwenden (z. B. `KI-Agent-vs-Chat` aus der Autocomplete-Liste wählen) – keinen Namen frei erfinden und nichts aus Codeblöcken klicken/kopieren, sonst entstehen Stub-Notizen (Standard-Ort dafür: Vault-Wurzel).

## Layout

- [ ] Notiz teilen: Rechtsklick **auf den Tab-Reiter** (Reiter oben, nicht in den Notiztext) → „Rechts teilen" – zwei Notizen nebeneinander; alternativ `Strg+P` → „teilen" tippen
- [ ] Neue Notiz anlegen (`Strg+N`) → landet automatisch in `00-Inbox/` → `Strg+P` → „Vorlage" tippen → „Vorlage einfügen" → Template „Wissensnotiz" wählen (Frontmatter wird automatisch gesetzt) → Thema als `# Überschrift` eintragen → im [[90-Index/Wissensindex]] verlinken; zur endgültigen Ordnung per Drag & Drop nach `10-Wissensbasis/` verschieben (oder `/vault-index` per OpenCode nutzen – siehe [[Agenten-Workflow]])

## Graph-Ansicht

- [x] `Strg+P` → „Graph-Ansicht öffnen" – Knoten von [[90-Index/Wissensindex]] verbinden alle Kernnotizen
- [x] (Optional) In einer Kernnotiz `Strg+P` → „Lokaler Graph" – Nachbarschaft einer einzelnen Notiz

## Aufräumen (falls passiert)

- [x] Versehentlich erzeugte Stub-Notizen löschen: Datei-Explorer → Rechtsklick → Löschen (z. B. eine Notiz `Notizname` in der Vault-Wurzel)

## Warum diese Übung?

Der Graph macht Wissensmanagement sichtbar: viele Verbindungen = gut vernetztes Wissen. Danach sind alle C.0-Punkte der [[10-Wissensbasis/Umsetzung-Checkliste]] erfüllt.
